Embedding the OVERHEAD globe

Add ?embed=1 to any OVERHEAD URL and the interface collapses to the globe, the headline counter, and hover/click cards. Replace the URL below with your own deployment (or http://localhost:3000/?embed=1 while developing).

Snippet

<div style="position:relative;aspect-ratio:16/10">
  <iframe
    src="https://YOUR-DEPLOYMENT/?embed=1"
    title="OVERHEAD"
    loading="lazy"
    style="position:absolute;inset:0;width:100%;height:100%;border:0"
  ></iframe>
</div>

Orbital data come from CelesTrak via the host app's own API routes, so embedding adds no extra load on CelesTrak.
